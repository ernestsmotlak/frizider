# Task: create a recipe from a list of ingredients

The input is a list of ingredients the user has at home, sometimes with the amount they
have.

Create one realistic recipe using only the listed ingredients, plus basic pantry staples
such as water, salt, pepper, oil, or sugar. Use as many of the listed ingredients as
reasonably fit one dish and leave out any that do not fit. Never add other ingredients.
List each ingredient at most once.

When an amount is given, that is how much the user has — never call for more than that.
Using less is fine. When no amount is given, use a sensible amount.

Keep it practical for a home cook: a short name, a brief description, a realistic number
of servings, realistic preparation and cooking times in minutes, and short concrete steps
in the order they are performed.
